# v2.4.5 免安装版：自动更新后的代理规则兼容修复

## 本次修复

- 修复 ChatGPT / Codex 自动升级后程序路径变化，增强代理仍只覆盖旧版路径，导致远程连接超时的问题。
- 受保护的代理后台每 15 秒检查运行中的程序版本及配套后台文件，兼容启动后才生成的 Codex core 和浏览器 helper。
- 新增路径前重新核验 Windows 注册包身份，以及后台文件与安装包原文件的 SHA256；只添加对应程序的精确路径和 TCP 443 规则。
- 补充规则时保持现有代理引擎和规则运行；校验或添加失败会保留原有规则，稍后重试。未变化的后台文件不会反复计算哈希。
- 同一会话不允许改变上游代理或应用包家族，最多保留 64 个已核验程序路径；达到上限后需重启启动器。

## 验证范围

本地通过 137 项代理断言、49 项免安装资源检查，以及启动等待、WebSocket 环境备份和托盘生命周期检查。已在 Windows 上确认能够从旧版路径识别当前 26.1029.7803.0 程序，并核验配套 core 和浏览器 helper；使用修复后的免安装启动器重启后，服务器返回当前电脑在线。

更新切换和失败回滚由模拟引擎回归检查覆盖；本次没有强制触发一次真实的 ChatGPT 自动升级。其他已保存电脑处于离线状态、上游网络故障或授权问题仍需分别处理，不承诺消除所有重连提示。

## 使用

下载 `LaunchDeck.exe`，完全退出旧客户端和托盘中的旧启动器，再从新版启动。运行中的旧后台不会自动加载新版启动器代码。

仍为单 EXE 免安装版，默认增强代理、无需额外勾选、不包含主题功能；保留浏览器修复、托盘保活和启动诊断。首次准备受保护组件和启用驱动仍需 Windows 授权。沿用已有浏览器入口兼容修复。

下载页同时提供 `LaunchDeck.exe.sha256`。详见 [免安装说明](../portable.md) 和 [技术记录](../remote-update-20261104.md)。
